Las carpetas dicen dónde está un taller. Las etiquetas dicen de qué trata, y un taller puede
llevar varias. En la app se llaman **Etiquetas**. Ejemplos típicos: «Onboarding»,
«Cliente Acme», «Estrategia», «remoto».

:::caution[No confundir]
En la interfaz alemana, la palabra para etiqueta («Tag») también significa jornada de taller. Por
eso todo lo que se refiere a una jornada de taller lleva expresamente **Jornada** en el nombre. El
campo **+ etiqueta** bajo el título de un taller, en cambio, siempre es una etiqueta.
:::

## Poner una etiqueta

1. Abre el taller.
2. Haz clic bajo el título en **+ etiqueta**.
3. Escribe la etiqueta y pulsa Intro.

Una etiqueta que aún no existe se crea en ese momento: no hay una gestión aparte de etiquetas, ni
hace falta. Las etiquetas valen para todo el espacio de trabajo: si escribes una palabra que
alguien ya ha usado, tu taller recibe exactamente esa etiqueta. Las mayúsculas y minúsculas no
cuentan: «onboarding» y «Onboarding» son la misma etiqueta.

Para quitarla, haz clic en la **×** junto a la etiqueta.

| Límite                   | Valor                     |
| ------------------------ | ------------------------- |
| Etiquetas por taller     | como máximo 12            |
| Longitud de una etiqueta | como máximo 40 caracteres |

Una etiqueta que ya no lleva ningún taller desaparece sola. Así la lista no se llena de palabras
que ya no encuentran nada.

:::note
Puede poner etiquetas quien tiene permiso para editar el taller. Quien solo puede leer (también un
invitado sin cuenta) ve las etiquetas bajo el título como texto y no puede cambiarlas.
:::

## Filtrar por etiquetas

En cuanto hay etiquetas en el espacio de trabajo, en la biblioteca aparece a la izquierda, debajo
de las carpetas, la sección **Etiquetas**. Junto a cada una se indica cuántos talleres la llevan.
Un clic en una etiqueta muestra solo esos talleres; además, las etiquetas aparecen en cada fila de
la lista.

- Un filtro por etiqueta sustituye al filtro por carpeta. Un clic en una carpeta o en **Todos los
  talleres** lo quita de nuevo.
- El campo **Buscar** actúa además: solo busca en los talleres con esa etiqueta.
- El filtro aparece en la dirección de la página. Una biblioteca filtrada por «Cliente Acme» es un
  enlace que puedes guardar o compartir.

Si la combinación no encuentra nada, la lista dice **No se ha encontrado nada.**

:::tip
El número junto a una etiqueta cuenta todos los talleres del espacio de trabajo, también los que
no puedes ver o los que están en la papelera. Si el filtro muestra menos resultados de los que
promete el número, esa es la razón.
:::

## ¿Carpeta o etiqueta?

|                    | Carpeta                                                               | Etiqueta                                  |
| ------------------ | --------------------------------------------------------------------- | ----------------------------------------- |
| Por taller         | como máximo una                                                       | hasta 12                                  |
| Anidable           | sí                                                                    | no                                        |
| Comparte el acceso | sí, una carpeta compartida comparte todo lo que contiene              | no                                        |
| Quién la crea      | cualquier miembro; cambiar el nombre y eliminar, solo administradores | quien tiene permiso para editar un taller |

Una regla práctica: carpetas para la estructura que comparten varias personas (clientes, equipos),
etiquetas para temas transversales que atraviesan esa estructura.
