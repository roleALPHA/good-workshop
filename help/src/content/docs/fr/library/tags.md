Les dossiers disent où se trouve un atelier. Les mots-clés disent de quoi il parle – et un atelier
peut en porter plusieurs. Dans l'application, ils s'appellent **Tags**. Exemples typiques :
« Onboarding », « Client Acme », « Stratégie », « à distance ».

:::caution[Ne pas confondre]
Dans l'interface allemande de GoodWorkshop, « Tag » désigne aussi une journée d'atelier. Tout ce
qui concerne une journée d'atelier s'appelle donc explicitement **Journée**. Le champ **+ tag**
sous le titre d'un atelier, en revanche, est toujours un mot-clé.
:::

## Attribuer un tag

1. Ouvre l'atelier.
2. Clique sous le titre sur **+ tag**.
3. Tape le mot-clé et appuie sur Entrée.

Un tag qui n'existe pas encore est créé au passage – il n'y a pas de gestion séparée des tags, et
on n'en a pas besoin. Les tags valent pour tout l'espace de travail : si tu tapes un mot que
quelqu'un a déjà attribué, ton atelier reçoit exactement ce tag. Les majuscules et minuscules ne
comptent pas : « onboarding » et « Onboarding » sont le même tag.

Pour retirer un tag, clique sur le **×** à côté.

| Limite            | Valeur                   |
| ----------------- | ------------------------ |
| Tags par atelier  | 12 au maximum            |
| Longueur d'un tag | 40 caractères au maximum |

Un tag qu'aucun atelier ne porte plus disparaît de lui-même. Ainsi, la liste ne se remplit pas de
mots qui ne trouvent plus rien.

:::note
Peut attribuer des tags quiconque a le droit de modifier l'atelier. Qui n'a que le droit de lecture
– y compris un invité sans compte – voit les tags sous le titre sous forme de texte et ne peut pas
les modifier.
:::

## Filtrer par tag

Dès qu'il existe des tags dans l'espace de travail, la bibliothèque affiche à gauche, sous les
dossiers, la zone **Tags**. À côté de chaque tag figure le nombre d'ateliers qui le portent. Un clic
sur un tag n'affiche plus que ces ateliers ; les tags figurent en outre sur chaque ligne de la
liste.

- Un filtre par tag remplace le filtre par dossier. Un clic sur un dossier ou sur **Tous les
  ateliers** le supprime.
- Le champ **Rechercher** s'y ajoute : il ne cherche que parmi les ateliers portant ce tag.
- Le filtre figure dans l'adresse de la page. Une bibliothèque filtrée sur « Client Acme » est un
  lien que tu peux enregistrer ou transmettre.

Si la combinaison ne donne rien, la liste affiche **Rien trouvé.**

:::tip
Le nombre à côté d'un tag compte tous les ateliers de l'espace de travail, y compris ceux que tu
n'as pas le droit de voir ou qui sont dans la corbeille. Si le filtre affiche moins de résultats que
le nombre ne le promet, c'est la raison.
:::

## Dossier ou tag ?

|                 | Dossier                                                   | Tag                                   |
| --------------- | --------------------------------------------------------- | ------------------------------------- |
| Par atelier     | un au plus                                                | jusqu'à 12                            |
| Imbriqué        | oui                                                       | non                                   |
| Partage l'accès | oui, un dossier partagé partage tout ce qu'il contient    | non                                   |
| Qui le crée     | chaque membre ; renommer et supprimer : admins uniquement | qui a le droit de modifier un atelier |

Une règle simple : les dossiers pour la structure que plusieurs personnes partagent (clients,
équipes), les tags pour les thèmes transversaux qui traversent cette structure.
