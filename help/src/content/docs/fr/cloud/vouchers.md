:::note
Cette page concerne uniquement GoodWorkshop Cloud. Seuls les admins peuvent utiliser des bons.
:::

Un bon accorde à ton espace de travail une réduction en pourcentage sur les factures
mensuelles. Certains valent pour un nombre de mois déterminé, d'autres sans limite de durée. Tu
reçois un code de bon de notre part, par exemple lors d'une opération promotionnelle.

## Utiliser un bon

Le code se saisit à l'endroit où figure aussi le moyen de paiement.

1. Ouvre le menu Compte en haut à droite et choisis, sous **Administration**, l'entrée
   **Facturation**.
2. Sous **Moyen de paiement**, saisis ton code dans le champ **Code de bon**. Les majuscules et
   minuscules n'ont pas d'importance.
3. Clique sur **Utiliser**.

Un bon s'applique à tes factures à partir du mois où tu l'utilises. Ensuite, à la place du
champ, s'affiche ce qu'il t'apporte :

| Affichage                                         | Signification                                              |
| ------------------------------------------------- | ---------------------------------------------------------- |
| « Bon CODE : 20 % de réduction sur tes factures » | Ce pourcentage est déduit de chaque facture.               |
| « Bon CODE : gratuit, sans facture »              | Le bon couvre tout. Il n'y a pas de facture pour ces mois. |
| « encore 3 mois »                                 | Le nombre de mois facturés qu'il couvre encore.            |
| « sans limite de durée »                          | Il s'applique tant que l'espace de travail est facturé.    |

Le pourcentage et la durée dépendent du bon. Ils sont fixés au moment où tu l'utilises et ne
changent plus ensuite.

:::tip
Seul un bon de 100 % sans limite de durée remplace le moyen de paiement : il n'y a alors jamais
rien à prélever, la période d'essai passe en **Actif** sans carte, et l'avis sur la période
d'essai disparaît. Tout autre bon ne le remplace pas – pas même un bon de 100 % pour trois mois.
Enregistre alors un moyen de paiement avant la fin de la période d'essai, sinon l'espace de
travail passe en lecture seule.
:::

## Comment les mois sont comptés

Chaque mois clos couvert par le bon compte comme l'un de ses mois – y compris un mois qui, grâce
à lui, coûte zéro euro. Un bon de trois mois, utilisé en mars après la période d'essai, couvre
donc les factures de mars, avril et mai. Les mois entièrement compris dans la période d'essai
ne sont pas facturés et ne comptent donc pas non plus.

Sur la facture, le code du bon figure dans la ligne de facturation, et la réduction y est
indiquée.

## Un seul à la fois

Un espace de travail n'a jamais qu'un seul bon en cours. Tant qu'un bon court, le champ pour en
utiliser un n'apparaît pas. Tu peux en utiliser un autre dès que celui en cours est terminé.

## Quand un code n'est pas accepté

| Message                                       | Ce que cela signifie                                                                    |
| --------------------------------------------- | --------------------------------------------------------------------------------------- |
| « Nous ne connaissons pas ce code de bon. »   | Le code n'existe pas ou a été retiré. Vérifie l'orthographe.                            |
| « Ce bon ne peut plus être utilisé. »         | Le délai pour l'utiliser est dépassé.                                                   |
| « Ce bon a déjà été entièrement utilisé. »    | Le code ne pouvait être utilisé qu'un certain nombre de fois, et ce nombre est atteint. |
| « Ton espace a déjà utilisé ce bon. »         | Chaque code ne vaut qu'une fois par espace de travail.                                  |
| « Un bon est déjà en cours pour ton espace. » | Attends que celui en cours soit terminé.                                                |

Un code se compose de lettres, de chiffres et de tirets. GoodWorkshop supprime de lui-même les
espaces au début ou à la fin.

:::note
Nous ne reprenons pas un bon déjà utilisé : même si un code est retiré plus tard, la réduction
que tu as obtenue continue comme promis.
:::
