Ordner sagen, wo ein Workshop liegt. Schlagwörter sagen, worum es geht – und ein Workshop kann
mehrere davon tragen. In der App heißen sie **Tags**. Typische Beispiele: „Onboarding“,
„Kunde Acme“, „Strategie“, „remote“.

:::caution[Nicht verwechseln]
In GoodWorkshop ist ein **Tag** auch ein Workshoptag. Alles, was einen Workshoptag betrifft,
heißt deshalb ausdrücklich **Workshoptag**. Das Feld **+ Tag** unter dem Titel eines Workshops
ist dagegen immer ein Schlagwort.
:::

## Einen Tag vergeben

1. Öffne den Workshop.
2. Klick unter dem Titel auf **+ Tag**.
3. Tipp das Schlagwort und drück die Eingabetaste.

Ein Tag, den es noch nicht gibt, wird dabei angelegt – eine eigene Verwaltung für Tags gibt es
nicht und braucht es nicht. Tags gelten für den ganzen Workspace: Tippst du ein Wort, das schon
jemand vergeben hat, bekommt dein Workshop genau diesen Tag. Groß- und Kleinschreibung zählen
dabei nicht, „onboarding“ und „Onboarding“ sind derselbe Tag.

Zum Entfernen klickst du auf das **×** neben dem Tag.

| Grenze            | Wert                 |
| ----------------- | -------------------- |
| Tags pro Workshop | höchstens 12         |
| Länge eines Tags  | höchstens 40 Zeichen |

Ein Tag, den kein Workshop mehr trägt, verschwindet von selbst. So füllt sich die Liste nicht mit
Wörtern, die nichts mehr finden.

:::note
Tags vergeben kann, wer den Workshop bearbeiten darf. Wer nur lesen darf – auch ein Gast ohne Konto –,
sieht die Tags unter dem Titel als Text und kann sie nicht ändern.
:::

## Nach Tags filtern

Sobald es im Workspace Tags gibt, steht in der Bibliothek links unter den Ordnern der Bereich
**Tags**. Daneben steht jeweils, wie viele Workshops den Tag tragen. Ein Klick auf einen Tag
zeigt nur noch diese Workshops; die Tags stehen außerdem in jeder Zeile der Liste.

- Ein Tag-Filter ersetzt den Ordner-Filter. Ein Klick auf einen Ordner oder auf **Alle
  Workshops** hebt ihn wieder auf.
- Das Feld **Suchen** wirkt zusätzlich: Es durchsucht nur die Workshops mit diesem Tag.
- Der Filter steht in der Adresse der Seite. Eine Bibliothek, gefiltert nach „Kunde Acme“, ist
  ein Link, den du speichern oder weitergeben kannst.

Findet die Kombination nichts, sagt die Liste **Nichts gefunden.**

:::tip
Die Zahl neben einem Tag zählt alle Workshops im Workspace, auch solche, die du nicht sehen darfst
oder die im Papierkorb liegen. Zeigt der Filter weniger Treffer, als die Zahl verspricht, ist das
der Grund.
:::

## Ordner oder Tag?

|               | Ordner                                              | Tag                                |
| ------------- | --------------------------------------------------- | ---------------------------------- |
| Pro Workshop  | höchstens einer                                     | bis zu 12                          |
| Verschachtelt | ja                                                  | nein                               |
| Teilt Zugriff | ja, ein geteilter Ordner teilt alles darin          | nein                               |
| Wer legt an   | jedes Mitglied; umbenennen und entfernen nur Admins | wer einen Workshop bearbeiten darf |

Eine Faustregel: Ordner für die Struktur, die mehrere Leute teilen (Kunden, Teams), Tags für
Querschnittsthemen, die quer durch diese Struktur laufen.
