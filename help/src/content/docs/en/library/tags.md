Folders say where a workshop sits. Tags say what it's about – and a workshop can carry several
of them. In the app they're called **Tags**. Typical examples: “Onboarding”, “Client Acme”,
“Strategy”, “remote”.

:::caution[Don't mix them up]
In the German interface, the word for a tag (“Tag”) also means a workshop day. That's why
everything about a workshop day is explicitly called **Workshop day**. The **+ tag** field
below a workshop's title, on the other hand, is always a keyword.
:::

## Add a tag

1. Open the workshop.
2. Click **+ tag** below the title.
3. Type the keyword and press Enter.

A tag that doesn't exist yet is created in the process – there is no separate tag management,
and none is needed. Tags apply to the whole workspace: if you type a word someone else has
already used, your workshop gets exactly that tag. Upper and lower case don't count, so
“onboarding” and “Onboarding” are the same tag.

To remove one, click the **×** next to the tag.

| Limit             | Value                 |
| ----------------- | --------------------- |
| Tags per workshop | at most 12            |
| Length of a tag   | at most 40 characters |

A tag that no workshop carries any more disappears by itself. That way the list doesn't fill up
with words that no longer find anything.

:::note
Anyone who may edit the workshop can add tags. Anyone who may only read – including a guest
without an account – sees the tags below the title as text and can't change them.
:::

## Filter by tags

As soon as the workspace has tags, the library shows a **Tags** area on the left below the
folders. Next to each tag is the number of workshops that carry it. Clicking a tag shows only
those workshops; the tags also appear in every row of the list.

- A tag filter replaces the folder filter. Clicking a folder or **All workshops** removes it
  again.
- The **Search** field works on top of it: it searches only the workshops with that tag.
- The filter is part of the page address. A library filtered by “Client Acme” is a link you can
  save or pass on.

If the combination finds nothing, the list says **Nothing found.**

:::tip
The number next to a tag counts all workshops in the workspace, including those you may not see
or that are in the bin. If the filter shows fewer results than the number promises, that's why.
:::

## Folder or tag?

|               | Folder                                       | Tag                            |
| ------------- | -------------------------------------------- | ------------------------------ |
| Per workshop  | at most one                                  | up to 12                       |
| Nested        | yes                                          | no                             |
| Shares access | yes, a shared folder shares everything in it | no                             |
| Who creates   | every member; only admins rename and remove  | anyone who may edit a workshop |

A rule of thumb: folders for the structure several people share (clients, teams), tags for
cross-cutting topics that run across that structure.
