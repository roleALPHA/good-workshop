This guide walks you once through everything you need for a first workshop day. All you need
is an account: in the cloud you get one when you [register](/en/cloud/sign-up/); in a
self-hosted installation an admin invites you under **Members**.

<Steps>

1. **Sign in**

   Open GoodWorkshop. On the **Sign in to GoodWorkshop** page you have two ways in, both without
   a password:

   - **Sign in with a passkey** – with your fingerprint, face or a security key, once you have
     set up a [passkey](/en/account/passkeys/).
   - Enter your e-mail address and choose **Send a sign-in link**. Open the link from the e-mail,
     and on the **Confirm sign-in** page click **Sign in**.

   The sign-in link works only once and only for a short time; how long is shown on the page
   after you request it.

2. **Create a workshop**

   You land in the library. Click **New workshop** at the top right, enter a title (for example
   “Strategy retreat”) and confirm with **Create** or the Enter key.

   GoodWorkshop opens the new workshop right away, and the first day – **Day 1** – is already
   there. If you had a folder selected on the left, the workshop goes into it; the field tells
   you where beforehand (“Filed in …”).

3. **Set up the day**

   Below the day tabs are the name, date and start of the day. Click the name to change it,
   pick a date and set the start time. A new workshop starts at 9:00 AM.

   You add more days with **Workshop day**; they take over the start time of the last day.

4. **Add blocks**

   Click **Add a block** below the agenda. The list of block types opens – check-in, input,
   group work, break and so on. Type a few letters to filter the list, and pick a type. The block
   appears at the end of the day, with the type's name as its title and its usual duration.

   Click the title to change it, and write below it what the block is about.

5. **Set the duration**

   The duration sits in the **Time** column below the start time. Click it and type it the way
   you think: `45`, `45m`, `1h`, `1:30` or `1h30`. All following start times recalculate
   immediately, and the header shows content, breaks and the number of blocks.

6. **Move blocks**

   Hover over a block; a handle appears on the left. Drag the block by it to its new place. On a
   phone, press and hold the handle briefly before you drag – that way a normal swipe still
   scrolls the page.

   With **Add section** you group several blocks under one heading, for example
   “Arrival & framing”.

7. **Share and print**

   At the top right of the workshop you'll find the output options:

   - **Access** – invite colleagues, or guests without an account.
   - **Print** – opens the print view in a new tab.
   - **Markdown** – downloads the schedule as a text file.

   **Whole workshop** outputs all days instead of only the open one. **With facilitation
   notes** includes your own notes; unchecked, they stay with you.

</Steps>

:::tip[Pin a time]
If a block has to start at a fixed time, such as lunch at 12:30 PM, click the open padlock that
appears next to the time in the **Time** column (**Fix start time**). The block then stays put
while you rearrange everything around it. More under [Duration and start times](/en/agenda/timing/).
:::

:::note
Passkeys need HTTPS. If a self-hosted installation runs without HTTPS, the sign-in page says
so – the sign-in link by e-mail still works.
:::
