:::note
This page applies only to GoodWorkshop Cloud. Only admins redeem vouchers.
:::

A voucher gives your workspace a percentage discount on its monthly invoices. Some apply for a
certain number of months, others with no end date. You get a voucher code from us, for example
from a promotion.

## Redeem a voucher

You enter the code where the payment method is.

1. Open the account menu at the top right and choose **Billing** under **Administration**.
2. Under **Payment method**, enter your code in the **Voucher code** field. Upper and lower case
   don't matter.
3. Click **Redeem**.

A voucher applies to your invoices from the month in which you redeem it. Afterwards, in place of
the field, it shows what it gives you:

| Display                               | Meaning                                                              |
| ------------------------------------- | -------------------------------------------------------------------- |
| “Voucher CODE: 20% off your invoices” | That percentage comes off every invoice.                             |
| “Voucher CODE: free, no invoice”      | The voucher covers everything. There is no invoice for these months. |
| “3 more months”                       | That's how many billed months it still covers.                       |
| “no end date”                         | It applies as long as the workspace is billed.                       |

The percentage and the duration depend on the particular voucher. They're recorded when you
redeem it and don't change afterwards.

:::tip
A voucher doesn't replace the payment method. Add one anyway before the trial ends, otherwise the
workspace becomes read-only afterwards – even with a 100% voucher.
:::

## How the months are counted

Every completed month the voucher covers counts as one of its months – including a month that
costs zero euros because of it. So a three-month voucher redeemed in March after the trial covers
the invoices for March, April and May. Months that fall entirely within the trial aren't billed
and therefore don't count either.

On the invoice, the voucher code appears in the invoice line, and the discount is shown there.

## One at a time

A workspace only ever has one running voucher. While one is running, the field for redeeming is
missing. You can redeem another one as soon as the running one has ended.

## When a code isn't accepted

| Message                                             | What it means                                                                                |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| “We do not know this voucher code.”                 | The code doesn't exist, or it was withdrawn. Check the spelling.                             |
| “This voucher can no longer be redeemed.”           | The redemption period has ended.                                                             |
| “This voucher has already been used up.”            | The code could only be redeemed a certain number of times, and that number has been reached. |
| “Your workspace has already redeemed this voucher.” | Each code applies only once per workspace.                                                   |
| “A voucher is already running for your workspace.”  | Wait until the running one has ended.                                                        |

A code consists of letters, digits and hyphens. GoodWorkshop removes spaces at the beginning or
end by itself.

:::note
We don't take back a voucher you've already redeemed: even if a code is withdrawn later, the
discount you got continues as promised.
:::
