:::

Ein Gutschein gibt deinem Workspace einen Rabatt in Prozent auf die monatlichen Rechnungen.
Manche gelten für eine bestimmte Zahl von Monaten, andere unbefristet. Einen Gutscheincode
bekommst du von uns, etwa aus einer Aktion.

## Einen Gutschein einlösen

Der Code wird dort eingegeben, wo auch die Zahlungsmethode steht.

1. Öffne oben rechts das Kontomenü und wähle unter **Verwaltung** den Eintrag **Abrechnung**.
2. Trag unter **Zahlungsmethode** im Feld **Gutscheincode** deinen Code ein. Groß- und
   Kleinschreibung spielen keine Rolle.
3. Klick auf **Einlösen**.

Ein Gutschein gilt ab dem Monat, in dem du ihn einlöst, für deine Rechnungen. Danach steht an
der Stelle des Felds, was er dir gibt:

| Anzeige                                            | Bedeutung                                                              |
| -------------------------------------------------- | ---------------------------------------------------------------------- |
| „Gutschein CODE: 20 % Rabatt auf deine Rechnungen“ | So viel Prozent gehen von jeder Rechnung ab.                           |
| „Gutschein CODE: kostenlos, ohne Rechnung“         | Der Gutschein deckt alles ab. Für diese Monate gibt es keine Rechnung. |
| „noch 3 Monate“                                    | So viele abgerechnete Monate deckt er noch ab.                         |
| „unbefristet“                                      | Er gilt, solange der Workspace abgerechnet wird.                       |

Die Prozentzahl und die Laufzeit hängen vom jeweiligen Gutschein ab. Sie werden beim Einlösen
festgehalten und ändern sich danach nicht mehr.

:::tip
Ein Gutschein ersetzt nicht die Zahlungsmethode. Hinterleg sie trotzdem vor dem Ende der
Testphase, sonst wird der Workspace danach schreibgeschützt – auch mit einem Gutschein über
100 %.
:::

## Wie die Monate gezählt werden

Jeder abgeschlossene Monat, den der Gutschein abdeckt, zählt als einer seiner Monate – auch ein
Monat, der durch ihn null Euro kostet. Ein Gutschein über drei Monate, eingelöst im März nach
der Testphase, deckt also die Rechnungen für März, April und Mai ab. Monate, die ganz in der
Testphase liegen, werden nicht abgerechnet und zählen deshalb auch nicht.

Auf der Rechnung steht der Gutscheincode in der Rechnungszeile, und der Rabatt ist dort
ausgewiesen.

## Einer zur Zeit

Ein Workspace hat immer nur einen laufenden Gutschein. Solange einer läuft, fehlt das Feld zum
Einlösen. Einen weiteren kannst du einlösen, sobald der laufende ausgelaufen ist.

## Wenn ein Code nicht angenommen wird

| Meldung                                                | Was es heißt                                                                              |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| „Diesen Gutscheincode kennen wir nicht.“               | Den Code gibt es nicht, oder er wurde zurückgezogen. Prüf die Schreibweise.               |
| „Dieser Gutschein kann nicht mehr eingelöst werden.“   | Die Frist zum Einlösen ist abgelaufen.                                                    |
| „Dieser Gutschein ist bereits aufgebraucht.“           | Der Code durfte nur eine bestimmte Zahl von Malen eingelöst werden, und die ist erreicht. |
| „Diesen Gutschein hat dein Workspace schon eingelöst.“ | Jeder Code gilt pro Workspace nur einmal.                                                 |
| „Für deinen Workspace läuft bereits ein Gutschein.“    | Warte, bis der laufende ausgelaufen ist.                                                  |

Ein Code besteht aus Buchstaben, Ziffern und Bindestrichen. Leerzeichen am Anfang oder
Ende entfernt GoodWorkshop von selbst.

:::note
Einen bereits eingelösten Gutschein nehmen wir nicht zurück: Auch wenn ein Code später
zurückgezogen wird, läuft der Rabatt, den du bekommen hast, wie zugesagt weiter.
:::
